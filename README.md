# Heyy there

## this is a System built with java to simulate a bank system with java and mySQL as the data base

### the methods used are as follows;
- depositFunds: this transfer funds from a ghost account to users account.
- withdrawFunds: this removes the amount of money account depending on how much the user asks for, it only works if the money is sufficient in the users account.
- transferFunds: this sends money to other accounts in the database given the account is found and the money being transferred is sufficient from the users account.
- signup: create a new account for the user.
- login: logs in to existing account given the username and password os correct.
- checkPassword: returns the value of the password as boolean.
- exit: log out of the current account.
- balance: keeps track of the money in the users account.
